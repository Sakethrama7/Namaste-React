-> The Best practice is to make separate files for separate components.
   Never ever place the Hard Coded data, strings inside the components folder.

-> There can be two types of exports and imports.
   -> Exports :
      1. Default Export : One way of export is default export. For one file you can only use one default export.
         you cannot write a default export twice in a file.
      2. Named Export : To export multiple components in a single file we need to use Named Exports.
   -> Imports :
      1. Default Import : import Component from "path"
      2. Named Import : import {Component} from "path"

-> What is React Algorithm and How React works behind the scenes?
   React uses something called as Reconcilliation Algorithm. This Algorithm is also known as React Fiber.
   This React Fiber came in React 16.
   Virtual DOM is actual representation of Actual DOM. Also it is the object.
   This Algorthim finds the difference between Old Virtual DOM and New Virtual DOM and then it will update the Actual DOM. That's how React becomes faster.
   So whenever there is change in any state variable, React will find out difference between virtual DOM and then re render the component.
